# Ashvera Technology — Hero Website

React + Vite + Tailwind CSS v4 + Framer Motion.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Customize before publishing

- Replace `public/images/ashvera-logo.png` with your clean original logo asset if available. The included logo crop comes from the reference hero image to match its navbar appearance.
- Replace `public/images/ashvera-laptop.webp` with a dedicated laptop image if you want an even closer match. The included image is cropped from the provided badge-free hero visual.
- Update the placeholder contact email `hello@ashvera.com`.
- Replace the short lower-page placeholder sections with verified company services, real projects, actual testimonials, and a working contact form.
- The included contact CTA currently scrolls to the contact section; the email link is a placeholder. No ASP.NET backend is connected in this frontend-only project.

## Stack

- React.js
- Tailwind CSS v4 via `@tailwindcss/vite`
- Framer Motion
- Lucide React icons
